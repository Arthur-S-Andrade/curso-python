# Curso de Python para Ciência de Dados

Neste curso aprendi fundamentos da lógica de programção em Python como:

- Inputs;
- Condicionais com if elif e else;
- Laços de repetição while e for;
- Estruturas de dados importantes como Listas, Tuplas e Dicionários;
- Criação de Funções;
- Importação de módulos;
- Trabalho com arquivos externos;
- Consumo de dados de uma API;
- Gestão de Ambientes Virtuais
